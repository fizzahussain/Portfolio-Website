## ✦ Overview

This repository contains my personal portfolio website, designed as an interactive **retro operating system + game world** rather than a conventional portfolio template.

It brings together:

- AI and Data Science work
- Machine Learning and analytics
- Software engineering and backend systems
- Algorithms, C++, operating systems, and low-level work
- UI / web development
- Experience and internships
- Community leadership, societies, and campus initiatives
- Art, painting, pottery, sports, and other creative side quests

The portfolio is intentionally built as a **single navigable experience**: visitors can explore through the HUD, World Map, project directory, skill tree, art browser, and interactive player world.

> **Main quest:** Make intelligence useful.  
> **Side quests:** Everything else.

## 🎮 Interactive Navigation

The landing screen opens into `PLAYER_WORLD.EXE`, which acts as the main navigation hub.

### World controls

- **WASD / Arrow Keys** — move the player avatar
- **Click inside the world** — walk to a location
- **Enter** — open a nearby portal
- **M** — open the World Map
- **A** — jump to the creative / art section
- **P** — jump to the project directory
- **1–8** — jump directly to portfolio sections

The same main pixel avatar is used throughout the interactive interface for a consistent visual identity.

The flagship **RAG Document Assistant** explores document ingestion, OCR fallback, faster-whisper, contextual chunking, pgvector, HNSW retrieval, grounded responses, citations, multi-user isolation and Dockerized services.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/fizzahussain/Portfolio-Website.git
cd Portfolio-Website
```

Start a local static server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

For Vercel deployment instructions, see [`DEPLOY.md`](DEPLOY.md).
