# FIZZA//2026 — Portfolio Arcade

A dependency-free, Vercel-ready personal portfolio for Fizza Hussain.

This version deliberately mixes:

- late-90s / early-2000s desktop UI
- pixel-game HUDs and level-select language
- retro system monitors
- a scrapbook-like personal archive
- a real interactive art browser
- AI/Data case-study storytelling
- project quest cards and project-property windows

The goal is **not** to cosplay one operating system exactly. It is to make the portfolio feel like an old personal computer and a game cartridge collided with an artist's desk and an AI lab.

## Run locally

No npm install is needed.

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy to Vercel

Import the folder/repository into Vercel as a static project. No build command or environment variables are required.

## Included work
