# FIZZA // STORY MODE

A dependency-free, Vercel-ready interactive portfolio for Fizza Hussain.

The site has two navigation styles:

- **Story Mode**: the selected avatar stays with the visitor and changes between technical and creative states while the portfolio unfolds as levels
- **Quick Explore**: opens the same content with the world map immediately available for recruiter-style scanning

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Deploy to Vercel

Import the repository into Vercel as a static site. No build command and no environment variables are required.

## Important content rules used in this version

- Only the two supplied pixel avatars are used as character avatars
- Live demo links are presented as demonstrations, not as replacements for the original repositories
- Project detail panels point visitors to the GitHub README for implementation depth
- The experience timeline is chronological
- Academic GPA/SGPA is not shown
- Art entries are limited to pieces already confirmed in the portfolio workflow
